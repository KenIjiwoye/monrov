# 231Booking

## Project Overview

231Booking is a mobile application built for the Liberia market.
It is a platform that will specialize in providing a seamless booking experience for users. Users can book anything from travel packages, hotel bookings, events, and more. Whatever the user books, we will ensure that the booking process is as smooth as possible. 

The application is built using the latest web technologies and is designed to be user-friendly and easy to navigate.

## Tech Stack

frontend: react native
backend: appwrite cloud

## Features

- User Authentication
- Booking System
- Payment System (stripe and Orange/MTN mobile money for Liberia)
- Push Notifications
- User Profiles (basic user, admin, and business user)
- Search and Filter
- Booking History
- Reviews and Ratings   
- Listings Management (create, update, delete, and view business listings for events, hotels, and more)
- Listings (view and book business listings)
